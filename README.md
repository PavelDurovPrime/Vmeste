# Рекламна агенція «Vmeste» (v.od.ua) — Редизайн лендінгу

Сучасний, адаптивний та конверсійний концепт лендінгу для **Рекламної агенції «Vmeste»** (м. Одеса).

## 🚀 Огляд проєкту
- **Офіційний сайт замовника:** [v.od.ua](http://v.od.ua)
- **Кабінет клієнта:** [kabinet.v.od.ua](https://kabinet.v.od.ua)
- **Стек:** HTML5, Tailwind CSS, Lucide Icons, Vanilla JavaScript

## 🌟 Ключові можливості
- **Каталог продукції (180+ послуг):** поліграфія, сувеніри та мерч, світлова зовнішня реклама, брендування транспорту, дизайн.
- **Живий пошук та фільтрація:** миттєвий пошук потрібної послуги в реальному часі.
- **Інтерактивний калькулятор:** прорахунок вартості замовлення з можливістю відправки готового ТЗ у **Telegram** або **Viber** в 1 клік.
- **Блок власного виробництва:** презентація парку обладнання (УФ-друк, лазерна порізка, шовкодрук, цех збирання).
- **Презентація особистого кабінету:** збереження макетів та історії замовлень.
- **Мобільна адаптація:** ергономічне меню та закріплена нижня панель швидких дій.

## 📂 Структура
- `index.html` — основний файл лендінгу
- `favicon.svg` — векторна іконка сайту
- `reply.txt` — варіанти комерційної відповіді для клієнта на email
- `img/` — логотип та оригінальні фотографії робіт
